# Presets

Ready-made stacks: a filled-in `stack/` folder plus matching `architecture.md` and `conventions.md`. `usecontextual init --preset <name>` lays one down, and setup uses it when the plan's stack matches.

Planned for v1:

- `next`: Next.js
- `laravel-inertia-react`: Laravel with Inertia and React

Not built yet. The example's `stack/` folder ([`example/context/stack/`](../example/context/stack/)) shows the shape a preset fills in.
