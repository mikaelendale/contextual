# Build — Auth

## Files
- `src/lib/auth.ts` · Better Auth's server config (see stack/better-auth.md).
- `src/lib/auth-client.ts` · the browser client.
- `src/lib/email.ts` · `sendEmail()`. In development it prints the email to the terminal; with `E2E=1` it also writes it to `.e2e/outbox.json`.
- `src/app/api/auth/[...all]/route.ts` · Better Auth's route handler.
- `src/app/(auth)/sign-in/page.tsx` · the sign-in page, with a "Check your email" state after sending.
- `src/app/(auth)/sign-in/sign-in-form.tsx` · client form calling `authClient.signIn.magicLink`.
- `src/proxy.ts` · redirects signed-out visitors from `/app/**` to `/sign-in`.
- `src/features/auth/session.ts` · `requireSession()`.
- `src/features/auth/components/account-menu.tsx` · the email address and Sign out, in the app shell.
- `src/db/auth-schema.ts` · generated tables.

## Data
`user`, `session`, `account`, `verification`, generated by `pnpm auth:generate` into `src/db/auth-schema.ts`. Migration `drizzle/0001_auth.sql`.

## Routes and actions
- `/sign-in` · the sign-in page.
- `/api/auth/*` · Better Auth's endpoints: sending and verifying magic links, signing out.

## Components
`Input`, `Button` (primary), and `Avatar` in the account menu.
